## Default Permission

Default permissions for the Amber NIP-55 signer plugin

#### This default permission set includes the following:

- `allow-is-amber-installed`
- `allow-login`
- `allow-sign-event`
- `allow-nip04-encrypt`
- `allow-nip04-decrypt`
- `allow-nip44-encrypt`
- `allow-nip44-decrypt`
