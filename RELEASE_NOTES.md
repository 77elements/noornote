# Release Notes 1.9.5

## New

- **Badge definitions (NIP-58):** badges on Nostr now resolve to their real name, description and image.

## Fixed

- Comment threads now show all nested replies (previously only top-level comments appeared).
- Quotes inside reposts load reliably — slow relays no longer leave "Quote could not be loaded" behind.
- Two wrong German labels fixed: the posting toast no longer says "Highlight posten" while waiting for signer approval.
