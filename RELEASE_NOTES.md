# NoorNote v0.9.0

## NosPress — your own website on Nostr (new)

- **NosPress Website Editor.** Build a personal multi-page website right inside NoorNote — published at `noornote.app/{your-nip05-or-npub}/`. Drag in headings, text, images, galleries, video, audio, embeds, bookmark folders, quotes, buttons, profile cards, articles lists, weblog feeds, navigation menus, columns and a portfolio block; style every block with a Properties panel and your own breakpoints, customize palette/fonts/SEO/Custom-CSS site-wide, set per-page headers and footers, export a ZIP backup any time.
- **DM button on foreign profiles.** Small round mail icon on every profile; click to message the user directly.

## Highlights & Git

- **NIP-84 Highlights.** Select text in any note or article and publish a highlight with your comment — visible across the timeline, profiles, single-note view, and as quoted previews. Other clients' highlights of your notes show up in your notifications.
- **NIP-34 Git events** open correctly from search and embeds; reply counts now include nested NIP-22 comments.

## Media

- **Pre-upload compression for video, audio and images** with a live progress overlay. Settings let you pick quality presets per kind, preserve formats (JPEG → JPEG, PNG → PNG), and toggle EXIF stripping (location, timestamps, device info).

## Lists

- **Deletions stick reliably across all lists.** Bookmarks, Tribes, and Follows now publish the deletion marker eagerly and remember locally what you removed, so deleted items don't reappear from stale relays.
- **Follow Pack timeline** shows what changed since you last looked (added/removed members, edited title/description/cover).
- **Move dropdown on every platform** for touch users and as a drag alternative.

## App

- About page now has a Credits section.

## Bugfixes & polish

- Scroll carousels are swipeable on mobile and resize cleanly inside narrow columns.
- Back-button takes one click again on public NosPress pages.
- Theme-color reactions, form borders, gradient-editor drag, and several smaller UI niggles fixed.
