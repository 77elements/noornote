# NoorNote v0.9.1 — NosPress Hotfix

## NosPress

- **Editor stays clean.** v0.9.0 accidentally applied the live-site styles to the editor preview too, which made blocks look styled and hard to interact with. Editor is now strictly schematic again — for a real preview, use "See Website".
- **Heading and Text blocks merged.** One block, with a tag picker in Properties (`p` / `h1`–`h6`). Existing heading blocks migrate automatically on load.

## Icons

- **Full icon set refresh** — every sprite icon now sourced from Lucide, uniform stroke and weight. Wallet-balance exchange arrows and the Lists sidebar icon look cleaner and more consistent.
