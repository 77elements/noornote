# NoorNote v0.8.9

## Desktop

- Fixed empty screen on the desktop app's first launch — the welcome / login screen (logged-out) and the timeline (logged-in) now render immediately after startup, no need to click into the sidebar first.

## Zaps

- Your outgoing zaps now appear as pills above the note (and on other clients like Yakihonne and Jumble) again. Zap receipts were quietly disappearing because the zap request was sent in a non-standard format that recent LNURL providers no longer accept.
