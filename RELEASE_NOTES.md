# NoorNote 1.2.0

**Reactions:** you can now react to a reaction. Tap an emoji to either add the same reaction or react to it, building little emoji threads you can expand right under the note. On mobile, long-press a reaction to open its thread.

**Notifications:** you get notified when someone reacts to your reaction.

**Web onboarding:** switched to the Sidecar browser signer, with a cleaner step order that matches desktop (key first, wallet last).

**Community Dhikr:** anonymous activity notifications with a jump straight to the Dhikr tab, plus a Diyanet refresh link in the prayer-times widget.

**Composer:** optional per-post client tag.

**Fix:** larger nostr.build uploads (up to 20 MiB in free tier), with clearer messages when a file is too big.
